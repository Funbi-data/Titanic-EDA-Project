# Titanic EDA Project

This project focuses on data preprocessing and exploratory data analysis (EDA) using the Titanic dataset.

## Objectives
- Handle missing values
- Encode categorical variables
- Detect outliers
- Perform exploratory data analysis
- Scale numerical features

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Key Insights
- Female passengers had higher survival rates
- Passenger class influenced survival
- Fare showed positive correlation with survival
- Outliers existed in Fare and Age columns

## Dataset
Titanic Dataset from Kaggle
